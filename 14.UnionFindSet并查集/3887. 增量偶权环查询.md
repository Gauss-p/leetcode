### 题目分析
题目要求按照给出的`edges`中的顺序，依次判断每条边是否满足：

> 	加入图中后使得图中所有的环路上的边权总和均为偶数

如满足，那么就将其加入，否则跳过，继续判断下一条边。

### 基本思路
最直接的想法就是，对于每一条边$[u_i, v_i, w_i]$，都先判断节点$u_i$和$v_i$之间是否存在通路对于两种情况：

> 	1.如果存在，就说明这条边加入后一定会形成新的环，那么计算它的权值总和，如果这个总和加上$w_i$是一个偶数，那么它就可以被加入，否则就不能被加入
> 	2.如果不存在，就说明这条边加入后不会形成环，那么直接添加即可

因此，为了判断两个节点是否有连接，并快速得出两个节点之间的路径权值总和，就需要使用并查集，不过需要注意的是，这里使用的并查集中，需要新增一个权值计算的功能。

### 权值计算功能
#### 定义
可以这样想，在同一个连通块中，如果已经计算出从其中的根节点开始到各个点的距离，那么这时候如果要求其中两个节点的权值总和，其实并不需要寻找这两个节点的最近公共祖先，因为题目只对奇偶性有要求，所以就算用根节点到两个节点的权值总和相加，由于`从根节点到两节点的最近公共祖先`这段路径重复累加了两次，故对奇偶性没有影响。

由上面一段的分析可知，如果对于每个节点都求出它到它所属的连通块的根节点的路径上权重总和，就可以快速求出两个节点之间的路径权重总和的奇偶性。故在并查集中定义一个列表`dist`，其中`dist[i]`即表示节点`i`到其所属连通块的根节点的路径权重总和**模除2**的值。

#### 实现
接下来要考虑的就是如何在并查集的两个函数`union`和`find`中更新`dist`列表。

在`union`函数中，为了计算路径权值，需要传入三个参数：两个节点$x$和$y$，以及`edges`给出的该边权值$w$。而为了整合判断能否加入的功能，则需令其返回值为一个布尔变量，`True`表示可以加入，`False`表示不能加入。首先用`find`函数求出两个节点所属的连通块的根节点$px$和$py$：

>	1.如果$px\neq py$ ，那么这条边加入后一定不会形成新的环路，因此将其加入，返回`True`
>	2.如果$px=py$，那么这条边加入后一定会形成新的环路，这时新的环路的路径权值总和就是$dist[x]+w+dist[y]$，如果它是偶数，就可以加入，返回`True`，否则返回`False`

在第一种情况下，需要将两个连通块进行合并，又因为`dist`定义的是从当前节点到所属连通块的根节点的路径权值和，那么如果将$py$合并到$px$之下，就需要更新：
$$dist[py] = (dist[x]+w+dist[y])$$
它表示：从$px$到$py$，走的是如下路径：
$$px\rightarrow x\rightarrow y\rightarrow py$$
同理，如果将$px$合并到$py$之下，只是将相同的值赋给$dist[px]$而已。

注意到在`union`函数中并没有更新整个连通块，因此在`find`函数中需新增更新连通块的部分。

### 实现细节
唯一需要注意的是，在这次的并查集中，新增了一个优化列表`rank`，其中`rank[i]`表示以`i`为根节点的子树的高度，这样，在`union`函数合并两个节点的时候，将`rank`值较小的那个合并在值较大的那个点下面，即可让整个树的高度尽可能的小。

### 复杂度
时间复杂度：$O(nlogn)$
空间复杂度：$O(n)$

### 代码
```python
class UFS:
    def __init__(self, n):
        self.pa = list(range(n))
        self.dist = [0]*n
        self.rank = [0]*n

    def find(self, x):
        if self.pa[x] != x:
            p = self.find(self.pa[x])
            # 在整条路径上逐层累加路径权值
            self.dist[x] = (self.dist[self.pa[x]]+self.dist[x])%2
            self.pa[x] = p
        return self.pa[x]

    def union(self, x, y, w):
        px, py = self.find(x), self.find(y)
        if px == py:
	        # 会形成环路
            if (self.dist[x]+self.dist[y]+w)%2 == 0:
                return True
            return False

		# 根据优化列表rank进行合并
        if self.rank[px] > self.rank[py]:
            self.pa[py] = px
            self.dist[py] = (self.dist[y]+w+self.dist[x])%2
        elif self.rank[py] > self.rank[px]:
            self.pa[px] = py
            self.dist[px] = (self.dist[y]+w+self.dist[x])%2
        else:
            self.pa[py] = px
            self.dist[py] = (self.dist[y]+w+self.dist[x])%2
            self.rank[px] += 1
                
        # if px < py:
        #     px, py = py, px
        #     x, y = y, x
        # self.pa[px] = py
        # self.dist[px] = (self.dist[y]+w+self.dist[x])%2
        return True

class Solution:
    def numberOfEdgesAdded(self, n: int, edges: List[List[int]]) -> int:
        ufs = UFS(n)
        res = 0
        for u, v, w in edges:
            if ufs.union(u, v, w):
	            # union函数返回值即为「能否添加该边」
                res += 1
        return res
```
